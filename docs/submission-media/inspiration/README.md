# Prior visual inspiration archive

This directory contains a small, curated subset of the earlier ChatGPT-generated
visual exploration for **Three in the Loop — A WebMCP Research Workbench**. It is
a human-review archive, not an approved media library.

Repository facts and the accepted product interface always override these images.
The generated images may inform composition, atmosphere, pacing, or channel
formats; they may never be presented as screenshots or proof of product behavior.

## Review outputs

- [Prior candidate contact sheet](prior-visual-contact-sheet.png) — the six
  strongest prior directions.
- [Hero direction contact sheet](hero-direction-contact-sheet.png) — current
  Hero, H-01/H-02/H-03 real crops, prior references, and the new hybrid draft.
- [Complete reconciliation](../prior-visual-review.md) — all 16 candidates,
  classification, factual corrections, public-safety review, and recommended uses.
- [Hybrid Hero draft](../drafts/01-hybrid-hero-real-activity-draft.png) — separate
  human-review draft; it does not replace the current Asset 01.

## Classification and folders

- `adapt/` contains class **B** references with valuable composition or channel
  ideas. Every file requires deterministic rebuilding with current facts and, when
  product UI is shown, replacement by a real screenshot.
- `archive/` contains class **C** records useful for retrospective, production
  planning, or video-format reference.
- No `direct-use/` directory exists because no prior generated image qualified as
  class **A**. Every candidate has an incorrect project identity, invented UI,
  obsolete content, or a combination of these issues.
- Class **D** images remain only in Downloads and were not duplicated here.

## Strict use rules

- Do not publish these generated images as real product UI.
- Do not import their old `WebMCP Research Workbench` identity in place of
  **Three in the Loop**.
- Do not reuse fake browser chrome, fake tool activity, fake source counts, fake
  citations, old domains, obsolete tools, or unsupported providers.
- Do not repeat claims such as `provenance-first`, `trustworthy results`,
  `production-ready`, `built for teams`, or `lightning fast` unless separately
  approved from current repository evidence.
- Use only real captures from `https://research.itprodirect.com/` for product
  evidence. Generated UI remains illustration even when it looks plausible.
- Preserve the exact current five-tool names and the human authority boundary.

No private account data, notifications, or local paths are visible in the copied
generated images. Some contain obsolete public URLs and fictional people/robots;
these are factual/style risks documented in the reconciliation, not private data.

## Regenerate review assets

The copied images and real screenshot originals are inputs to a deterministic
Sharp composition script:

```powershell
node docs/submission-media/source/build-prior-visual-review-assets.mjs
```

This rebuilds the two contact sheets and the non-overwriting Hybrid Hero draft.
It does not edit Assets 02, 03, 04, 05, or 06.
