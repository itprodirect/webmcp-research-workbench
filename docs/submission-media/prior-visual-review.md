## Classification

  rebuilding. None qualified.

  claims must be rebuilt.
- **C — archive/education:** useful as a production-history or format record, but
  not a lead visual direction.
- **D — reject:** obsolete, redundant, generic, materially misleading, or too
  difficult to correct reliably.
