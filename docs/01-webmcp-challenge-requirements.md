# WebMCP Challenge Requirements — Working Snapshot

**Snapshot date: 2026-08-27**

**Must be re-verified before submission**

This document records the currently accepted planning assumptions for the challenge:

- Submission deadline: September 3, 2026 at 1:00 PM Pacific.
- A live URL is required.
- The project must work in the supported ChatGPT in-app browser or supported WebMCP-enabled Chrome environment.
- A public code repository is required.
- An open-source license is required before submission.
- A public YouTube demo under three minutes, with audio, is required.
- The project description must explain the WebMCP fit and the value of the human-agent workflow.
- Existing projects require meaningful challenge-period WebMCP additions; this project is new.
- Judges currently evaluate:
  - WebMCP Leverage;
  - Execution;
  - Potential Impact;
  - Creativity & Ambition.
- Submitted materials should be frozen during judging according to current challenge guidance.
- AI development assistance is permitted.

This is a dated working snapshot, not an authoritative or legal source. It intentionally contains no invented citations.
